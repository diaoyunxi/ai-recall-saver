# Security Policy

## Supported Versions

Only the latest release (or `main`/`master` branch HEAD) receives security updates.

## Reporting a Vulnerability

If you discover a security vulnerability, please report it responsibly:

1. **Do not** open a public issue.
2. Email the maintainer via the contact info in the repository profile.
3. Include:
   - A description of the vulnerability
   - Steps to reproduce
   - Potential impact
   - Suggested fix (if any)

You should receive a response within 72 hours.

## Scope

**In scope**: Code vulnerabilities (XSS, injection, etc.), auth bypasses, sensitive data exposure
**Out of scope**: Third-party dependency issues, social engineering, DoS against hosted services
