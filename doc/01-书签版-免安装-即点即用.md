## 🔖 书签版（免安装，即点即用）

如果你不想安装 Chrome 扩展，可以直接使用书签版。在任何支持的 AI 网页版（DeepSeek、Kimi 等）点击书签即可加载防撤回功能。

### 添加书签

1. 在浏览器书签栏空白处右键 → **添加网页…**
2. **名称**填写：`AI撤回保存器`
3. **网址**填写以下代码（完整复制，包括开头的 `javascript:`）：

```javascript
javascript:(function(){fetch('https://raw.githubusercontent.com/diaoyunxi/ai-recall-saver/main/bookmarklet.js').then(r=>r.text()).then(t=>{let s=document.createElement('script');s.textContent=t;document.head.appendChild(s);}).catch(e=>alert('加载失败: '+e.message));})();
```

> 💡 **提示**：如果 `raw.githubusercontent.com` 访问困难，可将上述网址中的 `https://raw.githubusercontent.com/diaoyunxi/ai-recall-saver/main/bookmarklet.js` 替换为镜像地址，如 `https://ghproxy.com/https://raw.githubusercontent.com/diaoyunxi/ai-recall-saver/main/bookmarklet.js`

### 使用方法

1. 打开任意支持的 AI 网页版（如 [chat.deepseek.com](https://chat.deepseek.com)）
2. 点击书签栏上的 **AI撤回保存器** 书签
3. 页面右下角会出现 🛡 悬浮按钮，显示脚本已加载
4. 当 AI 回复被撤回/重新生成/删除时：
   - 页面原位置会出现「⚠ 已撤回」恢复块
   - 悬浮按钮角标数字 +1
   - 出现 Toast 提示
5. 点击悬浮按钮打开侧边面板，查看/复制/导出所有撤回记录
6. 撤回记录保存在内存中，刷新页面即清空
7. 可通过浏览器控制台（F12 → Console）查看所有捕获的记录：`window.__AISaver__.records`

### 高级配置（书签版）

在点击书签前，可在浏览器控制台（F12 → Console）执行以下代码来覆盖默认配置：

```javascript
window.__AISaverConfig__ = {
  sensitivity: 'balanced',  // 'strict' | 'balanced' | 'aggressive'
  debugMode: false           // true | false
};
```
