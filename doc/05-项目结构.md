```
ai-recall-saver/

│   ├── sites.js               # 各站点 DOM 选择器配置

├── popup/
│   ├── popup.html             # 工具栏弹窗

│   └── popup.css              # 弹窗样式
├── icons/                     # 扩展图标 PNG
└── README.md
```
